# 用量指标（snow-rate-limits）

Snow App **面板插件**（`renderMode: esm`），只统计五个指标：RPD、TPD、RPM、ITPM、OTPM。统计数据是本机全部请求的合计，不区分 API 档案。没有输入栏入口，只从面板标签打开。

## 视觉结构

数据海报式布局，不是常规的表单/卡片页：

- **顶部信息条**：一行小字号等宽字（本机用量 / 选中区间）+ 在途状态与刷新按钮。
- **背景画布**：8 条缓慢起伏的等高线，透明度 6% 左右，只做氛围，不参与交互。`prefers-reduced-motion` 下只画一帧。
- **范围轨道**：横向可滚动的预设带，激活项后面的胶囊由弹簧积分跟随（`requestAnimationFrame` + 速度衰减），不是 CSS 过渡。
- **指针读数**：在指标带区域移动指针时，x 位置映射到分钟序列索引，五条迷你曲线同时画出竖线与圆点，顶部显示该点时间，每条指标的「光标」格显示该时间点的数值。
- **指标带**：五条，每条是 `序号 / 超大缩写 / 中文名 / 超大数值 / 三个元数据格（日均或峰值 · 今日或实时 · 光标）/ 迷你曲线`。指针进入即成为焦点：缩写染强调色、左侧竖线、迷你曲线提亮。
- **迷你曲线**：把区间内的分钟序列按桶取最大值降采样到 96 点，用 Canvas 画面积 + 折线；范围超过 36 小时没有明细，曲线、峰值与光标一起留空。

## 指标与三格

| 指标 | 主数值（区间） | 元数据格 |
| --- | --- | --- |
| RPD 每日请求 | 区间请求总数 | 日均 / 今日 / 光标 |
| TPD 每日 Token | 区间 token 总数（输入 + 输出） | 日均 / 今日 / 光标 |
| RPM 每分钟请求 | 请求数 ÷ 区间分钟数 | 峰值 / 实时 / 光标 |
| ITPM 输入 Token/分 | 输入 token ÷ 区间分钟数 | 峰值 / 实时 / 光标 |
| OTPM 输出 Token/分 | 输出 token ÷ 区间分钟数 | 峰值 / 实时 / 光标 |

「光标」格跟随指针在曲线上的位置，显示该分钟的数值；没有明细（范围 > 36 小时）时为「—」。

区间均值按选定跨度折算，包含没有请求的时间段，所以「全部」这类长跨度会被拉低——这是折算口径，不是数据缺失。

## 时间范围

今天 / 昨天 / 近 7 天 / 近 30 天 / 本月 / 上月 / 全部 / 自定义（两个日期框）。全部按本地时区的自然日边界。

峰值与迷你曲线只在范围 ≤ 36 小时时计算：需要拉明细（分页，单次最多 2000 条）做分钟分桶。超过 36 小时显示「—」，并在下方说明。选中已经结束的区间时，同一次挂载内不重复拉明细。

## 刷新节奏

| 区块 | 间隔 |
| --- | --- |
| 实时值（60 秒窗口） | 5 秒 |
| 今日累计 | 30 秒 |
| 区间汇总与峰值 | 30 秒 |
| 在途会话 | runtime 域实时推送 |

面板不可见（`isActive === false`）时轮询与背景动画都暂停。顶部信息条显示在途会话数与输出 token。

## 口径与边界

- 只用 `usage` 元数据域（`plugin.json` 已声明 `usage`），不读档案列表。
- 明细在请求完成时落库：正在流式输出的会话不计入 60 秒窗口，也不计入已完成区间。
- 统计范围是本机 Snow App 的请求，同一密钥下其它客户端不计入。
- 输入 token 含缓存读写，直接取宿主 `summary`，不做二次拆分。
- 界面选择（范围预设、日期）存在插件私有存储 `view` 键，不含任何用量数据。

## 安装

```text
config-set scope=plugins key="new" value={sourceDir: "F:\\desktop\\code\\snow-plugins\\snow-rate-limits"}
```

覆盖安装：

```text
config-set scope=plugins key=com.seagull.rate-limits value={sourceDir: "F:\\desktop\\code\\snow-plugins\\snow-rate-limits"}
```

## 文件

```text
snow-rate-limits/
  plugin.json        # 清单：esm 面板 + usage 隐私声明（无 chatInput 入口）
  index.js           # 单文件入口：数据逻辑 + 画布绘制 + 海报渲染
  style.css          # 前缀 .srl-，cqi 字号与容器查询响应式
  locales/           # zh-CN / en 扁平词典
  selftest.mjs       # 口径自检 + 首帧渲染冒烟（node，78 项）
```

## 自检

```text
node snow-rate-limits/selftest.mjs
```

覆盖：时间串互转、七种范围预设（含跨月、跨年）与自定义日期校验、36 小时峰值窗口判定、summary 口径、单位速率折算、分钟请求/输入/输出峰值、分钟序列与降采样（含空序列与目标值下限）、fmtRate、视图归一化，以及首帧渲染冒烟（五个指标带、十个元数据格、五条曲线、八个预设、不再渲染大标题）。真实宿主的渲染、画布与 `usage` 返回值仍需打开面板验收。
