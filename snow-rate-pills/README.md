# 用量胶囊（snow-rate-pills）

Snow App **脚本插件**（客户端脚本，`@snow-target client` + `@snow-scope global`），与面板插件 `com.seagull.rate-limits` 同口径，把五项用量指标做成可自由拖放的胶囊。

## 形态

| 项 | 取值 |
| --- | --- |
| 名称 / 文件 | 用量胶囊 / `snow-rate-pills.user.js`（脚本无插件 id，按仓库 `snow-<name>/` 目录约定） |
| 胶囊数量 | 6 颗：5 颗指标 + 1 颗范围控制；每颗可单独显示 / 隐藏 |
| 指标胶囊内容 | `缩写 + 数值 + 单位`，例如 `RPD 812`、`ITPM 8.1k/分` |
| 范围胶囊 | `范围 今天`，点击（或聚焦后回车 / 空格）循环切换预设 |
| 默认位置 | 窗口顶部居中（顶栏下方 56px），一行放不下自动换行，每行独立居中 |
| 拖放 | 任意胶囊可拖到窗口任意位置；拖动过的记住坐标，没拖过的跟随窗口宽度重新居中 |
| 数据刷新 | 默认 10 秒，可在菜单里切到实时（1 秒）；标签页隐藏时跳过 |

指标口径：

| 胶囊 | 取值 |
| --- | --- |
| RPD | 所选范围的请求总数（默认今天） |
| TPD | 所选范围的输入 + 输出 token |
| RPM | 最近 60 秒请求数 |
| ITPM | 最近 60 秒输入 token |
| OTPM | 最近 60 秒输出 token |

范围预设：今天 / 昨天 / 近 7 天 / 近 30 天 / 本月 / 上月 / 全部，按本地自然日边界。RPM / ITPM / OTPM 恒为最近 60 秒，不随范围变化。

## 胶囊宽度

- 宽度由内容决定，没有固定尺寸；内部记住每颗胶囊的**历史最大宽度**并写成 `min-width`，数值滚动途中位数变化不会让胶囊忽宽忽窄。
- 某颗一旦变宽就立刻按新宽度重排一次（排布用的正是这个宽度值），所以不会压到右边那颗；重排的位置变化走 `left` / `top` 过渡，看起来是滑过去而不是跳，拖动过程中禁用该过渡以保证跟手。
- 文本没变时不重复测量（`getBoundingClientRect` 会强制同步布局），测量只发生在数值落到终值那一次。
- 字体是等宽的，宽度基本只随字符数变化，所以滚动途中先用字符数挡一道：只有字符数创新高才真正测一次像素并抬高 `min-width`，重排推迟到滚动结束。

## 顶栏入口

仪表按钮挂在宿主顶栏**待办区域（`.top-bar-todo-menu`）的左侧**，通知推送中心的铃铛挂在同一区域的右侧，两侧各占一边。待办区域尚未出现时贴标题组右侧；两者都找不到时退回 `topbar.actions` 插槽。

> 为什么锚在容器外：宿主顶栏是 `.top-bar-main > [header-title-group, top-bar-todo-menu, top-bar-main-trailing]`，其中 `top-bar-todo-menu` 按会话状态动态创建与重建。锚点落在这个容器内部时，容器一重建，插进去的按钮就跟着消失、再由观察器挂回来——表现就是图标一直在闪，点击恰好落在被抽掉的节点上就点不开。
>
> 按钮被 React 重建后由 `MutationObserver` 重挂，回调用 `requestAnimationFrame` 合并，只在位置确实不对时才移动节点；宿主顶栏重建的空窗期不摘按钮，保持原位等锚点回来。
>
> 顶栏同时是宿主的窗口拖拽区（`.top-bar` 上是 `app-region: drag`），按钮上显式声明了 `-webkit-app-region: no-drag`；菜单开合走 `click` 与 `pointerup` 双通道（300ms 内只处理一次），拖拽区里 click 被系统吞掉时仍能响应。

点开菜单：

- 六颗胶囊的逐颗开关（右侧显示「显示中 / 已隐藏」）
- 全部显示 / 全部隐藏
- 切换统计范围（右侧显示当前范围）
- 刷新速度（档位滑块，右侧显示当前档位）
- 光效时长（档位滑块，右侧显示当前档位）
- 重置胶囊位置（回到顶部居中布局）
- 立即刷新用量

菜单支持 Esc 与点击外部关闭，超出视口时自动翻到按钮上方。同样的操作也注册成脚本菜单命令（插件列表 → 脚本插件 → 菜单命令）。

## 显示 / 隐藏（逐颗）

- **隐藏某一颗**：鼠标移到该胶囊上，右侧出现圆形 X，点一下只隐藏这一颗；顶栏菜单里也可以逐颗切换。
- **隐藏后的排布**：被隐藏的胶囊不再参与顶部居中排布，其余胶囊自动重新居中；手动拖过的胶囊坐标保留。
- **恢复**：顶栏菜单列出全部六颗，每颗右侧标注「显示中 / 已隐藏」，点一下即可切换；另有「全部显示」「全部隐藏」两个批量项。
- **脚本菜单命令**：全部显示胶囊、全部隐藏胶囊、切换用量统计范围、切换刷新速度、切换光效时长、重置胶囊位置、立即刷新用量。
- 状态存在 GM `srp.state` 的 `off` 集合（`{ rpd: true, … }`）；旧版整体隐藏的布尔 `hidden` 在读取时自动展开成「六颗全部隐藏」。

## 刷新动效（Reactbits 风格）

数值变化的那颗胶囊按这套组合播放，一次播放的时长由「光效时长」档位决定（3 / 5 / 8 / 12 秒，默认 3 秒）：

1. **数字滚动**（Count Up）：原始数值从旧值缓动到新值，取光效时长的 35%（默认 910ms）easeOutCubic，每帧按该指标自身的格式重新渲染（RPD / RPM 用千分位，TPD / ITPM / OTPM 用 k / M / B 紧凑写法）。
2. **边框光束**（Border Beam）：一个比胶囊大的旋转锥形渐变方块（`conic-gradient` 白光 → 强调色 → 青色，两端渐隐）配一层内部遮盖，只在胶囊外沿留 2px 光环绕行一圈。**不使用 `@property`**（部分宿主 Chromium 不播 `@property` 自定义属性动画，之前因此看不到光束），只用 `transform: rotate()` 动画。
3. **文字高光**（Shiny Text）：数值上一条柔和白光扫过，跑两轮。这段用 `background-clip:text` + 透明字色渲染，文字颜色完全来自背景渐变，所以渐变必须始终盖住元素：背景放大到 250% 后，位移只允许落在 `0%`–`100%`（越界会让背景整块滑出元素，字就变成透明的看不见）；`prefers-reduced-motion` 下没有动画可依赖，直接退回实色字。
4. **抬升**：胶囊轻微上浮、阴影加深，带回弹曲线。

收尾不做硬切：光束的淡出占后半段的大头（`-beam-fade` 在 42% 之后一路衰减到 0），同时 `.srp-beam` 与文字高光都带 `transition`，所以「持续不停」档结束或换档把动画摘掉时也是淡出，不会瞬间消失；抬升与阴影同样走过渡回落。

同一颗胶囊上一轮动效没播完不重播（1 秒档下数值每秒都在变，逐帧重播会变成一直抖），所以高频刷新时动效是连续播放而不是反复从头开始。顶栏按钮只做一次强调色点亮、不做缩放，避免顶栏图标跟着抖。首次加载不触发（没有上一个值不算变化）；`prefers-reduced-motion` 下跳过滚动与动画，直接落到最终数值。

## 刷新速度

| 档位 | 1 秒（实时） | 2 秒 | 5 秒 | 10 秒（默认） | 30 秒 | 60 秒 |
| --- | --- | --- | --- | --- | --- | --- |

- 顶栏菜单里是一条档位滑块：1 秒（实时）/ 2 / 5 / 10（默认）/ 30 / 60 秒，右侧显示当前档位（1 秒显示为「实时 · 1 秒」）。拖动只切档位与读数，松手才重启定时器并立刻刷一次，免得拖动过程中反复打元数据查询。
- 脚本菜单命令「切换刷新速度」仍是循环切档，给菜单关着时用。
- 1 秒是宿主元数据轮询的下限，也是本插件的最快档；档位存在 GM `srp.state` 的 `intervalMs`，非法值回退 10 秒。
- 高频刷新时数值与标题都走「文本节点 `nodeValue` + 值去重」写入，不产生 `childList` 变动，不唤醒其它脚本的 `MutationObserver`；滚动动画只在格式化结果真正变化的那一帧才写 DOM，边框光束按胶囊节流到每「光效时长」一次。1 秒档下顶栏按钮不再有任何 DOM 变动。

## 光效时长

| 档位 | 3 秒（默认） | 5 秒 | 8 秒 | 12 秒 | 持续不停 |
| --- | --- | --- | --- | --- | --- |

- 顶栏菜单里是一条档位滑块：3 / 5 / 8 / 12 秒与「持续不停」，松手后立即在可见的第一颗胶囊上放一次，方便对着实际效果挑；脚本菜单命令「切换光效时长」仍是循环切档。
- 「持续不停」= 光束无限绕行、文字高光无限扫动，抬升只做进场那一次；因为不再重播，数值持续变化也不会把动画打断。此时一圈按最短档 3 秒走。
- 档位经 CSS 变量 `--srp-tick-ms`（时长）与 `--srp-tick-repeat` / `--srp-tick-shine-repeat`（循环次数）传给动画：光束绕行、文字高光、抬升、数字滚动（取时长 35%，持续档按 3 秒算）四者一起收尾，节流窗口用的是同一个值。
- 值存在 GM `srp.state` 的 `tickMs`（`0` = 持续不停），非数字回退默认档，其它数值吸附到最近的档位（旧版本存的 2.6 秒之类会自动落到 3 秒档）。

## 数据与边界

- 只读 `usage` 元数据域（`@snow-privacy usage`），不读档案列表、不联网。
- 明细在请求完成时落库，流式中的会话不计入 60 秒窗口。
- 本机 Snow App 的请求才算，同一密钥下其它客户端不计入。
- `usage` 未授权时五颗指标显示 `—`，悬停提示会说明需要声明 usage。

## 安装

```text
config-set scope=userscripts key="new" value={sourcePath: "F:\\desktop\\code\\snow-plugins\\snow-rate-pills\\snow-rate-pills.user.js"}
```

安装后在 **插件 → 插件列表 → 脚本插件** 里可编辑与启停；脚本运行在默认沙箱档（隔离世界），不需要完全权限。

## 文件

```text
snow-rate-pills/
  snow-rate-pills.user.js   # 脚本本体（含 #region pure 纯函数区）
  selftest.mjs              # 纯函数自检（node，105 项）
  README.md
```

## 自检

```text
node snow-rate-pills/selftest.mjs
```

覆盖：时间格式化、七种范围预设（含跨年 lastMonth）、summary 归一（缺字段按 0）、数字格式化与五颗指标的格式化映射、刷新速度档位归一（含非法值回退）、光效档位（档位表、缺省与非法回退、最近档吸附、持续档语义、滚动时长换算、读数写法）、坐标夹取（越界、负值、视口小于胶囊）、顶部居中排布（单行居中、换行、超宽胶囊各自成行）、顶栏落位判定（位置已对不搬动、锚点换兄弟才搬、父级不同要搬、插槽不重复追加）、状态归一（非法范围、非法坐标、auto 标记、逐颗 off 集合与旧版整体 hidden 的展开）。真实宿主的 DOM 行为与 `usage` 返回值仍需在应用里验收。
