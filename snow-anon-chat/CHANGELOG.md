# Changelog

## 0.5.0（2026-10-15）

消息格式支持对齐官方客户端常用子集（基于官方客户端 bundle 帮助文案 + hack-chat/main README 核实）：

- 行内：`**粗体**`、`*斜体*`、`~~删除线~~`、`` `行内代码` ``、`[文字](链接)`、裸链接自动识别、`![图片](地址)`、`$公式$` / `$$公式$$`
- 块级：```` ```语言 代码块 ````（保留空白 + 语言标签）、`#` 标题、`>` 引用（嵌套）、`---` 分隔线、列表、GFM 表格
- 外链图片经宿主 `img-proxy` 协议加载（面板 CSP 不放行直连外链）
- 安全：不解析原始 HTML（React 元素渲染自动转义）；链接/图片仅放行 http(s)，`javascript:`/`data:` 一律拒绝
- 新增头部「消息格式」帮助浮层，列出全部支持写法（三语言）
- 已知简化：代码块不做语法着色；公式以源码样式呈现（不内嵌 highlight.js / KaTeX，控制体积）

## 0.4.1（2026-10-15）

- 修复固定昵称失效：初始化时 client 持有加载前的旧配置对象，首次连接按旧配置解析昵称（表现为永远用随机昵称）；现在存储加载完成后同步回 client
- 修复设置保存无反馈：存储写入失败不再静默，显式报错并回滚内存配置；固定昵称非法（非 1-24 位字母/数字/下划线）保存时即拦截提示；保存成功才显示「已保存」

## 0.4.0（2026-10-15）

- 设置面板新增连接区：自动连接开关、桥端口（默认 8799）、代理地址（留空自动探测本机常见代理端口）
- 代理经 hello 握手下发，修改代理无需重启桥进程；`upstreamError` 与传输层错误分离提示
- 三语言键 65 → 80
