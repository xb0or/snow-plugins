# snow-stt-launcher（本地语音服务）

Snow App **面板插件**：启动 / 停止 / 重启 / 状态检测 [snow-voice-io](../snow-voice-io/) 使用的本地 whisper 转写服务。

> **需与 [snow-voice-io](../snow-voice-io/) 客户端脚本配合使用**：本面板只负责「起服务 + 管模型」，
> **本身不提供语音输入**。语音输入 / 朗读由 `snow-voice-io` 脚本完成——两者要一起装，
> 缺了脚本面板没有输入入口，缺了面板则需自己用命令行启动服务。

## 功能

- **状态检测**：请求 `http://127.0.0.1:<端口>/ping`，显示运行状态、模型名、线程数、**推理后端**、**推理进程**（常驻 whisper-server / 每次加载的 whisper-cli）。
- **启动**：后台运行 `python stt_server.py <端口>`（分离进程，不占用终端标签页）。
- **停止**：按监听端口定位进程并结束（常驻子进程随主进程一起回收）。
- **重启**：先停 → 轮询等端口真正释放 → 再起。服务端代码更新、或想回收常驻推理进程时用它。
- **推理后端**（服务区内）：默认「自动」——服务端按 `cuda > vulkan > cpu` 探测可用后端并自动选用，CPU 始终兜底；也可手动强制某个后端。切换会重新探测并重启常驻推理进程。
- **当前模型**（服务区内）：下拉切换后**自动重启服务**使其立刻生效；服务未运行时只保存选择。
- **模型库**：列出可下载的 whisper 模型，一键下载（带进度）、删除已装模型；下载按 `Content-Length` 校验完整性，断流会如实报错而不是留下残缺文件。
- **设置**：端口、下载源、下载代理、服务目录，保存在插件本地存储。

## 模型下载与删除

模型由**服务端后台线程**下载（面板的 `api.net.fetch` 有 5 MB 响应体上限，下不了大文件），面板只负责触发与显示进度。

- **下载源（三选）**：
  - `官方 huggingface.co` —— 国内通常需代理
  - `镜像 hf-mirror.com` —— 国内可用，视网络而定
  - `魔搭 ModelScope` —— **国内直连、无需代理**（默认自动直连，不走应用代理）
- **下载代理**：留空时按「环境变量 → Snow App 代理配置 → Windows 系统代理」自动回退；魔搭源默认直连。需要手动指定时填入地址（如 `http://127.0.0.1:7897`）。
- **自定义模型**：可填任意 ggml 模型（`.bin`）的 URL 下载。
- **删除**：已安装模型行显示「删除」按钮（需二次确认）。若被删的是当前生效模型，服务会自动回退到目录中下一个可用模型，无需重启。
- 模型保存到服务目录的 `whisper/` 下。

## 安装

插件安装后出现在顶栏 **加号菜单 → 插件** 分组与右侧面板标签体系，打开即用。AI 也可用 `config-set scope=plugins` 自动安装。

> 面板声明了 `terminal` 隐私域（启动/停止服务需要创建终端会话执行命令）。停止时只结束监听该端口的进程。

## 前置条件

1. **Python 3** 在 PATH 中可用。
2. 服务目录内存在 `stt_server.py` 与 whisper 运行时（`whisper/bin/Release/whisper-cli.exe` 与 `whisper/ggml-*.bin`），默认即 `snow-voice-io/stt-service`。

## 与 snow-voice-io 的关系

| | 作用 |
| --- | --- |
| snow-voice-io（客户端脚本） | 录音 → 调本机转写服务 → 回填文本；朗读 AI 回复 |
| snow-stt-launcher（本插件） | 控制那个本机转写服务的启停与状态 |

**两者需配合使用**：只装脚本不装面板，服务得起不来（除非手动用命令行启动）；
只装面板不装脚本，面板本身没有语音输入入口。两者通过 `127.0.0.1:<端口>` 通信，
各自独立安装、可独立升级。

## 实现说明

- 状态检测走 `api.net.fetch`（主进程网络栈）；启动/停止走 `terminal` 写动作。
- 启动命令以分离进程方式运行（`Start-Process -WindowStyle Hidden`），下发后立即关闭该临时终端，因此列表中不会残留终端标签页。
- 配色全部使用宿主主题 CSS 变量，明暗主题自动跟随；图标内嵌官方 Lucide SVG。
